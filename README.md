# mypocket

A collection of simple, focused Flutter mini-apps for daily life.

## Overview

**mypocket** is a suite of lightweight tools designed to help you build better habits, track small wins, and simplify everyday tasks. Each mini-app is minimal, fast, and easy to use.

## Mini-Apps Roadmap

| #   | App Name                | Description                                        | Status  | Notes |
| --- | ----------------------- | -------------------------------------------------- | ------- | ----- |
| 1   | 2-Minute Timer          | Quick-reset 2-minute timer for focused bursts      | Planned |       |
| 2   | Daily 3-Task Planner    | Write and check off 3 daily tasks, minimal UI      | Planned |       |
| 3   | Screen-Free Score       | Track hours spent away from your phone             | Planned |       |
| 4   | Micro Gratitude Journal | One-sentence daily gratitude prompt                | Planned |       |
| 5   | Breath Coach            | Animated breathing with customizable patterns      | Planned |       |
| 6   | Mini Water Tracker      | One-tap water logging with visual progress         | Planned |       |
| 7   | $5 Daily Tracker        | Log and sum purchases under $5                     | Planned |       |
| 8   | Subscription Watcher    | List recurring charges and get renewal reminders   | Planned |       |
| 9   | Impulse Delay           | Log wish-to-buy items, 24h delay before purchase   | Planned |       |
| 10  | Quote Collector         | Save, shuffle, and get random inspirational quotes | Planned |       |
| 11  | Random Decision Maker   | Coin flip, dice, and wheel for quick decisions     | Planned |       |
| 12  | Tiny Memory Game        | Super quick matching game for a mental break       | Planned |       |
| 13  | Clipboard History       | Stores your last 10 copied items for easy access   | Planned |       |
| 14  | Voice-to-Note           | Quick voice notes with automatic transcription     | Planned |       |
| 15  | Daily Algorithm Gen.    | One random daily coding challenge                  | Planned |       |
